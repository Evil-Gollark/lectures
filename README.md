# 课表小程序 · 第 3 版：找共同空闲时间

把几个人的课表放在一起，算出**所有人都空着**的时间段，按「越长越靠前」排序。顺便把「打印课表」和「结束」分成两个菜单项。

> **需求三**：找共同空闲时间 —— 输入多个人的课表，算出所有人的共同空闲时段；结果按「越长越靠前」排序。

**版本脉络**：v1 读入课表（单文件 `in_put.py`）→ v2 算空闲时段（拆成 `lectures.py` + `timetable.py`）→ **v3 找共同空闲时间（多人课表比对）**。

## 这一版做了什么

- 新增「共同空闲时段」：**一人一个 CSV**，先各算各的空闲，再逐天取交集。
- 结果按长度从长到短排序（同样长的按星期几、开始时间排，保证每次输出稳定）。
- 人的名字直接取 CSV 的文件名（`张三课表.csv` → `张三课表`），不用额外输入。
- 菜单从 4 项变成 6 项：**`3` 打印课表**（打印完回到菜单）、**`6` 结束**，不再「结束的时候顺带打印」。
- 命令行多了 `--common`；`--csv` 可以给多次。

## 功能

- **共同空闲**：`--common --csv 张三课表.csv --csv 李四课表.csv`，逐天求所有人空闲段的交集。
- **排序输出**：按分钟数从大到小；同长度按「星期几 → 开始时间」排。
- **一眼看出谁有多少课**：标题下面会写 `参与的人（2 位）：张三课表（4 节课）、李四课表（5 节课）`。
- **课间提示**：时长 ≤ `gap`（默认 15 分钟）的空档标 `（课间）`。
- **菜单分工**：`3` 打印课表 / `4` 看单人空闲 / `5` 找共同空闲 / `6` 结束，打印完不再自动退出。
- 单人部分（CSV 容错读入、连堂合并、空闲时段）与第 2 版相同。

## 运行

```bash
# 交互模式（1 手动录入 / 2 从csv读入 / 3 打印课表 / 4 查看空闲时段 / 5 找共同空闲 / 6 结束）
python lectures.py

# 单人的课表 / 空闲时段（和第 2 版一样）
python lectures.py --csv 张三课表.csv
python lectures.py --csv 张三课表.csv --free

# 多人的共同空闲时段（一人一个 CSV；人名就用文件名）
python lectures.py --common --csv 张三课表.csv --csv 李四课表.csv

# 也可以自定义可用范围和连堂间隔
python lectures.py --common --csv 张三课表.csv --csv 李四课表.csv --window 09:00-21:00 --gap 20
```

## 选项

| 选项 | 说明 |
| --- | --- |
| `--csv 课表.csv` | 要读入的 CSV，**可以给多次**（一人一个）；后面不给路径时弹文件选择框 |
| `--common` | 算所有给的课表的共同空闲时段 |
| `--free` | 打印单人的「空闲时段」视图 |
| `--window 08:00-22:00` | 每天的可用时间范围，默认 `08:00-22:00`；结束写 `24:00` 或 `00:00` 都算到当天结束 |
| `--gap 15` | 连堂判定间隔（分钟），默认 15；`0` 表示不合并 |
| `-h`, `--help` | 打印用法 |

几点约定：

- 给了多份 `--csv` 但**没加** `--common` → 直接报错并提示：「给了多份课表；看共同空闲请加 --common，看单人课表请只给一份」（退出码 2）。
- 加了 `--common` 但只给了一份课表 → 会提示「只给了一份课表…」，然后按单人空闲处理。
- 加了 `--common` 却一份 `--csv` 都没给 → 报错（退出码 2）。

## CSV 格式

四列，顺序固定（带不带表头都行）。仓库里的 `张三课表.csv` 和 `李四课表.csv` 就是示例：

```csv
课程名,星期几,开始时间,结束时间
高等数学,星期一,08:00,09:50
大学英语,星期一,10:00,11:40
数据结构,星期二,14:00,15:40
体育,星期四,16:00,17:40
```

- **星期几**：`星期一` / `周一` / `礼拜一` / `一` / `1` / `mon` / `monday` 都认。
- **时间**：`8:00`、`08：00`（全角）、`8点30`、`8.30`、`8`（= `8:00`）都认。

## 实现要点

- **共同空闲 = 逐天取交集**：先对每份课表调 `free_slots` 算出各自每天的空闲段，再把同一天所有人的空闲段两两求交（`_intersect_pair` 负责「两组里任意两段互交」，`intersect` 负责把多组一路交下去）。
- **人名来自文件名**：`load_timetable` 用 `os.path.splitext(os.path.basename(path))[0]` 当人名，所以不用额外输入，也不怕 CSV 里没写名字。
- **排序键是 `(-分钟数, 星期几, 开始时间)`**：先按长度从长到短，长度相同时按星期几、再按开始时间，保证同样输入每次输出顺序都一样（不会今天一个样明天一个样）。
- **`intersect` 是「对一组时间段列表取交集」**：`intersect(a, b, *others)`，中间任何一步交集为空就提前结束，不会白算。
- **`--common` 的三种情况都处理了**：不给 CSV 报错；只给一份就提示并按单人算；给了多份但没加 `--common` 也报错，避免用户以为自己看到的是共同空闲。
- **菜单 `3` 和 `6` 分开**：`3` 只打印、打印完回到菜单；`6` 才结束。这样「打印课表」和「结束程序」互不牵连。
- **菜单 `5` 的地址留空 = 弹文件选择框**：用的是 `choose_csv()`（图形框优先、没有图形环境退回控制台按编号选），取消或输 `q` 就结束录入。

## 已知限制

- 共同空闲只在**同一周 7 天**的框架里算，不涉及日期、单双周。
- 每个人都要单独一个 CSV 文件（人名取文件名）；没有「一个 CSV 里加一列姓名」的写法。
- 可用范围不能跨天（`22:00-02:00` 这种不支持）。
- 相邻但不重叠的两段空闲不会被合并；只有课与课之间 ≤ `gap` 的相邻小节会合并成一块。
- 交集只按「时间区间重叠」算，不考虑“谁愿意早起”之类的偏好。
