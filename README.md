# 课表小程序 · 第 1 版：读入课表

把一周的课表读进来，打印成一份「本周课表」的文本视图。

> **需求一**：读入课表 —— 支持手动录入或从 CSV 读入（字段：课程名、星期几、开始时间、结束时间），打印出「本周课表」的文本视图。

**版本脉络**：v1 读入课表（单文件 `in_put.py`）→ v2 算空闲时段（拆成 `lectures.py` + `timetable.py`）→ v3 找共同空闲时间（多人课表）。

## 功能

- **从 CSV 读入**：自动尝试 `utf-8-sig` / `utf-8` / `gbk` 三种编码，中文 Excel 另存的 CSV 直接能用。
- **表头可有可无**：没有表头就按「课程名、星期几、开始时间、结束时间」的顺序读；有表头时支持中英文别名（`课程名`/`课程`/`name`…、`星期几`/`周几`/`day`…、`开始时间`/`start`…、`结束时间`/`end`…）。
- **坏行不炸**：字段不足、课程名为空、时间写错、结束早于开始 —— 逐行打印 `[警告]` 跳过，剩下的照常读入。
- **手动录入**：一行一条，直接回车结束。
- **自动去重**：课程名 + 星期几 + 开始 + 结束 完全相同的算同一条，重复的会打印 `[提示] 重复课程，已跳过：…`。
- **本周课表视图**：按 星期一 → 星期日 顺序列出，用 `├─` / `└─` 画树；那天没课就显示 `（无课）`；中文按全角宽度对齐，不会歪。
- **选文件**：CSV 路径留空时会弹出系统文件选择框；没有图形环境（或 tkinter 不可用）就退回「列出当前目录的 .csv 按编号选」。

## 运行

```bash
# 交互模式（菜单：1 手动录入 / 2 从 CSV 读入 / 3 结束并打印）
python in_put.py

# 直接读一个 CSV 并打印课表
python in_put.py --csv 课表示例.csv

# --csv 后面不给路径 = 打开文件选择框
python in_put.py --csv
```

这一版只认 `--csv` 一个参数，没有 `-h`；其他参数会被忽略。

## CSV 格式

四列，顺序固定（带不带表头都行）：

| 列 | 含义 | 例 |
| --- | --- | --- |
| 1 | 课程名 | 高等数学 |
| 2 | 星期几 | 星期一 |
| 3 | 开始时间 | 08:00 |
| 4 | 结束时间 | 09:40 |

```csv
课程名,星期几,开始时间,结束时间
高等数学,星期一,08:00,09:40
大学英语,星期一,10:00,11:40
数据结构,星期三,14:00,15:40
体育,星期五,16:00,17:40
```

写法很宽松：

- **星期几**：`星期一` / `周一` / `礼拜一` / `一` / `1` / `mon` / `monday` 都认（`日`、`天`、`7`、`sun` 也认）。
- **时间**：`8:00`、`08：00`（全角冒号）、`8点30`、`8.30`、`8`（= `8:00`）都认。

## 代码结构

单文件 `in_put.py`（429 行），从上到下四块：

| 行 | 内容 |
| --- | --- |
| 55-92 | 解析：`_norm`、`_DAY_MAP` / `parse_day`、`_FULLWIDTH` / `parse_time` |
| 95-182 | 数据：`Time`（时间点）、`Lecture`（一次课）、`Timetable`（课次集合，`_seen` 去重） |
| 184-279 | 读入与打印：`read_csv`、`_width` / `_center`、`output` |
| 281-429 | 交互与入口：`_ask`、`choose_csv`（→ `_pick_file_gui` / `_pick_file_console`）、`input_manual`、`main` |

## 实现要点

- 时间统一存成 `(hour, min)` 两个整数；`Time.__lt__` 只比这个 key，比较和显示互不牵扯。
- 去重的唯一标识是 `Lecture.key() = (课程名, 开始时间的 key, 结束时间的 key)`，而时间的 key 里含星期几，所以同一门课在不同时间段算两条。
- 课表视图固定 46 个半角字符宽，`_center` 用 `unicodedata.east_asian_width` 判断全角（宽度算 2）来补空格，中文列不会歪。
- 首行是不是表头，靠「第二列能不能解析成星期几」来判断，这样没有表头的文件也能直接读。

## 已知限制

- 只支持一周 7 天，没有单双周 / 多周 / 起止周。
- 时间精确到分钟，不支持秒。
- 交互模式里 `1` 是**追加**录入；想改错的那一条只能重开程序。
- 打印时不会合并同一门课的连续两节（这是第 2 版才加的功能）。
