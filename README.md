# 课表小程序 · 第 2 版：算空闲时段

在第 1 版（读入并打印课表）的基础上加了「算空闲时段」：给定每天的可用时间范围（默认 `08:00-22:00`），算出每天有哪些空档；同一门课的连续两节自动合并成一块，**不会**出现 `09:00-09:45`、`09:55-10:40` 这种碎片。

> **需求二**：算空闲时段 —— 给定每天的可用时间范围（如 08:00—22:00），算出每天的空闲时段；同一课程连续两节要合并显示，不要碎片。

**版本脉络**：v1 读入课表（单文件 `in_put.py`）→ **v2 算空闲时段（拆成 `lectures.py` + `timetable.py`）** → v3 找共同空闲时间（多人课表）。

这一版还把单文件拆成了「入口 + 库」：`lectures.py` 管菜单和参数，`timetable.py` 放数据结构和算法。

## 功能

- 第 1 版的全部功能：CSV 读入、编码/表头/坏行容错、手动录入、去重、本周课表视图、文件选择框。
- **空闲时段视图**（`--free` 或菜单 4）：每天按可用范围切出「有课 / 空闲」交替的时间轴，末尾给出本周空闲合计。
- **连堂合并**：同一门课两节之间休息不超过 `gap` 分钟（默认 15）就合并成一块 —— 课表视图里标 `（2 节合并）`，空闲视图里也不会再切出 `09:45-09:55` 这种碎片。
- **可用范围可改**：`--window 09:00-18:00`（结束写 `24:00` 表示到零点）。
- **两个视图共用一套合并逻辑**：`--gap` 对「课表」和「空闲时段」都生效。

## 运行

```bash
python lectures.py                                              # 交互模式
python lectures.py --csv 课表.csv                                # 读入并打印课表
python lectures.py --csv 课表.csv --free                         # 只打印空闲时段
python lectures.py --csv 课表.csv --free --window 09:00-18:00 --gap 15
```

| 选项 | 说明 |
| --- | --- |
| `--csv [路径]` | CSV 路径；留空或省略路径则弹文件选择框 |
| `--free` | 打印「空闲时段」而不是「本周课表」 |
| `--window 08:00-22:00` | 每天的可用范围（默认 `08:00-22:00`；结束写 `24:00` 表示到零点） |
| `--gap 15` | 同一门课两节之间休息 ≤ 这么多分钟就算连堂（默认 15；`0` = 不合并） |
| `-h`, `--help` | 显示帮助 |

## CSV 格式

和第 1 版一样，四列顺序固定（带不带表头都行）：

```csv
课程名,星期几,开始时间,结束时间
高等数学,星期一,08:00,09:40
大学英语,星期一,10:00,11:40
数据结构,星期三,14:00,15:40
体育,星期五,16:00,17:40
```

- **星期几**：`星期一` / `周一` / `礼拜一` / `一` / `1` / `mon` / `monday` 都认。
- **时间**：`8:00`、`08：00`（全角冒号）、`8点30`、`8.30`、`8`（= `8:00`）都认。

## 实现要点

- `Slot` 里的时间**全用「从 0 点起的分钟数」存**，不存 `Time` 对象：`08:00-24:00` 的右端点 1440 分钟用 `Time` 表示不出来（`hour` 只能是 0~23）。
- **合并分两步**：
  1. 先按 `(星期几, 课程名)` 分组、组内按时间排序，前一块的结束到后一块的开始不超过 `gap` 就接起来 —— 消碎片只认这一步；
  2. 再把**不同课程之间真正重叠**的块合并（撞车），标成 `A、B（时间冲突）`，**不会**用 `gap` 去硬粘两门不同的课。
- 时间段按**左闭右开** `[begin, end)` 理解：`09:40` 结束和 `09:40` 开始不算重叠，相接处不会凭空多出一段 0 分钟的空档。
- `--gap` 同时作用于「课表」和「空闲时段」两个视图；交互模式下在菜单 4 里改过的 gap，之后打印课表也照着用。
- 课表的合计**只算上课时间、不含课间**：所以连堂示例显示的是 `共 2 节课，合计 1 小时 30 分钟`，而那一块显示为 `09:00-10:40`。

## 已知限制

- 只区分「有课 / 没课」，不认周末、节假日、单双周。
- 时间精确到分钟，不支持秒。
- 空闲视图里的 `（课间）` 标记表示这段空档不超过 `gap` 分钟（可以理解成一节连堂课里的小休息）。
- 交互模式里 `1` 仍是追加录入，改错一条只能重开。
