# 课表小程序 · 第 3 版：找共同空闲时间

这一版加了「多人共同空闲」：把几个人的课表 CSV 一起读进来，算出**所有人都有空**的时段，并按「越长越靠前」排序。顺手把交互菜单里的「打印课表」和「结束进程」拆成了两件事。

> **需求三**：找共同空闲时间 —— 输入多个人的课表，算出所有人的共同空闲时段，结果按「越长越靠前」排序。

**版本脉络**：v1 读入课表（单文件 `in_put.py`）→ v2 算空闲时段（拆成 `lectures.py` + `timetable.py`）→ **v3 找共同空闲时间（多人课表）**。

仓库里带了两份示例课表：`张三课表.csv`（4 节课）、`李四课表.csv`（5 节课）。

## 功能

- 第 1、2 版的全部功能：CSV 读入与容错、手动录入、去重、本周课表视图、空闲时段视图（`--free`）、连堂合并（`--gap`）、可用范围（`--window`）、文件选择框。
- **共同空闲**（`--common` 或菜单 5）：**一人一份 CSV**，逐份算各自的空闲（各自按 gap 合并连堂），再把同一天所有人的空闲段逐个取交集，最后按长度从长到短列出，并给出最长的一段和本周合计。
- **菜单职责拆开**：菜单 3 只打印课表、留在菜单里；菜单 6 才是结束 —— 结束的时候不会再顺手打印一份课表。
- **多份 CSV**：`--csv` 可以给多次（一人一个文件）；人名直接用文件名，不用额外输入。

## 运行

```bash
python lectures.py                                                    # 交互模式
python lectures.py --common --csv 张三课表.csv --csv 李四课表.csv       # 多人的共同空闲时段
python lectures.py --csv 课表.csv --free                               # 单人空闲时段
```

| 选项 | 说明 |
| --- | --- |
| `--csv [路径]` | CSV 路径，可以给多次（一人一个文件）；留空则弹文件选择框 |
| `--common` | 求多份课表的共同空闲时段，按长度从长到短列出 |
| `--free` | 打印「空闲时段」而不是「本周课表」 |
| `--window 08:00-22:00` | 每天的可用范围（默认 `08:00-22:00`；结束写 `24:00` 表示到零点） |
| `--gap 15` | 同一门课两节之间休息 ≤ 这么多分钟就算连堂（默认 15；`0` = 不合并） |
| `-h`, `--help` | 显示帮助 |

## CSV 格式

和前两版一样，四列顺序固定（带不带表头都行）；**共同空闲时一个人给一个文件**：

```csv
课程名,星期几,开始时间,结束时间
高等数学,星期一,08:00,09:40
大学英语,星期一,10:00,11:40
数据结构,星期二,14:00,15:40
体育,星期四,16:00,17:40
```

- **星期几**：`星期一` / `周一` / `礼拜一` / `一` / `1` / `mon` / `monday` 都认。
- **时间**：`8:00`、`08：00`（全角冒号）、`8点30`、`8.30`、`8`（= `8:00`）都认。
- **人名**：直接取文件名（去掉 `.csv`），所以 `张三课表.csv` 在结果里就叫「张三课表」。

## 代码结构

还是两个文件，第 3 版在库里加了「交集」和「共同空闲」这一块：

| 文件 | 行数 | 内容 |
| --- | --- | --- |
| `lectures.py` | 265 | 入口：`_USAGE`、`_parse_args`（新增 `--common`）、`_ask_free_options`、`main`（6 项菜单 + 命令行分支） |
| `timetable.py` | 688 | 库：数据结构、读入、合并、三个视图（课表 / 空闲 / 共同空闲） |

第 3 版新增的部分（`timetable.py`）：

| 行 | 名字 | 作用 |
| --- | --- | --- |
| 252 | `load_timetable` | 读一个 CSV，返回 `(人名, 课表)`，人名取文件名 |
| 506 | `_intersect` | 两个时间段取交集，同一天才交，相接不算（返回 `None`） |
| 516 | `_intersect_pair` | 两组时间段两两取交集，结果按开始时间排序 |
| 528 | `intersect` | 对一组（或多组）空闲段连乘交集，某一组空了就提前结束 |
| 542 | `common_free` | 每个人的空闲段取交集 → `{星期几: [空闲段]}` |
| 560 | `output_common` | 排序并打印「共同空闲时段」 |

`timetable.py:13-21` 的 `__all__` 也从 19 项变成了 22 项（加了 `load_timetable`、`intersect`、`common_free`、`output_common`），因为入口用的是 `from timetable import *`，新名字不进 `__all__` 就拿不到。

## 实现要点

- **排序键是 `(-分钟数, 星期几, 开始时间)`**：先长后短；长度一样时按星期几、再按开始时间排，所以每次运行的结果顺序都一样。
- **人名取文件名**：`load_timetable` 用 `os.path.splitext(os.path.basename(path))[0]`，所以 `张三课表.csv` 显示成「张三课表」。
- **边界情况**：一份课表都没给 → 每天整个可用范围；只给一份 → 就是那个人的空闲时段（和 `--free` 的结果一致）。
- 命令行里给了多份 `--csv` 却不加 `--common` 会直接报错（提示「看共同空闲请加 `--common`，看单人课表请只给一份」），免得悄悄只看了一个人的课表。

## 已知限制

- 只看「有课 / 没课」，不考虑地点、赶路时间、线上课。
- 人越多交集越小，结果里可能有不少短段 —— 目前没有「只显示 ≥ N 分钟」这类过滤。
- 只支持一周 7 天，不分单双周；时间精确到分钟，不支持秒。
- 交互模式里 `1` 仍是追加录入，改错一条只能重开。
