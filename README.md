# 课表小程序 · 第 2 版：算空闲时段

给一周划出可用的时间范围（默认每天 `08:00-22:00`），算出每天真正空着的时段；并且把同一门课连着上的两节合并成一块，不显示成一串碎片。

> **需求二**：算空闲时段 —— 给定每天的可用时间范围（如 08:00—22:00），算出每天的空闲时段；要能把同一课程连续两节合并显示，不要出现 `09:00-09:45`、`09:55-10:40` 这种碎片。

**版本脉络**：v1 读入课表（单文件 `in_put.py`）→ **v2 算空闲时段（拆成 `lectures.py` + `timetable.py`）** → v3 找共同空闲时间（多人课表比对）。

## 这一版做了什么

- 把 v1 的单文件拆成**入口 `lectures.py` + 库 `timetable.py`**（顺便修掉原来「打印课表」和「结束」捆在一起的问题之前的状态）。
- 新增 `Slot`（一段时间的区间对象）与合并算法，提供「空闲时段」视图。
- 新增 `--free`、`--window`、`--gap` 三个参数，菜单里多了「4 查看空闲时段」。
- 合并对**课表视图也生效**：`--csv 连堂demo.csv` 打印出来的就是 `09:00-10:40  高等数学（2 节合并）`。

## 功能

- **连堂合并**：同一门课的两节之间隔 ≤ `gap` 分钟（默认 15）就合成一块，显示 `高等数学（2 节合并）`；三节连堂也能合成一块。
- **时间冲突**：不同课程真正重叠时合并成一块并标注 `A、B（时间冲突）`（注意：只是挨着、没重叠的两门课不会被硬粘在一起）。
- **空闲时段**：把每天的可用范围减去课表，得到空闲段；列表里课和空闲交替显示，一眼看出哪段时间空着。
- **课间提示**：空档时长 ≤ `gap` 分钟（默认 15）时机注 `（课间）`，提醒它其实是课间而不是整块空闲。
- **越界提示**：课超出可用范围时会打印 `[提示] …超出可用范围，只按范围内计算`。
- 其余（CSV 容错读入、去重、手动录入、文件选择框）与 v1 相同，代码原样搬进了库。

## 运行

```bash
# 交互模式（1 手动录入 / 2 从csv读入 / 3 结束并打印 / 4 查看空闲时段）
python lectures.py

# 打印课表（连堂自动合并）
python lectures.py --csv 连堂demo.csv

# 看空闲时段
python lectures.py --csv 连堂demo.csv --free

# 自定义可用范围和连堂间隔
python lectures.py --csv 连堂demo.csv --free --window 09:00-18:00 --gap 10

# 看用法
python lectures.py -h
```

## 选项

| 选项 | 说明 |
| --- | --- |
| `--csv 课表.csv` | 读入的 CSV；后面不给路径（或整个参数不给）时弹文件选择框 |
| `--free` | 打印「空闲时段」视图（不加则只打印课表） |
| `--window 08:00-22:00` | 每天的可用时间范围，默认 `08:00-22:00`；结束写 `24:00` 或 `00:00` 都算到当天结束 |
| `--gap 15` | 连堂判定间隔（分钟），默认 15；`0` 表示不合并 |
| `-h`, `--help` | 打印用法 |

可用范围的分隔符 `-`、`~`、`～`、`—`、`–`、`至` 都认，全角冒号也认。

## CSV 格式

四列，顺序固定（带不带表头都行）。仓库里的 `连堂demo.csv` 就是一份示例（星期一有连着上的两节高等数学）：

```csv
课程名,星期几,开始时间,结束时间
高等数学,星期一,09:00,09:45
高等数学,星期一,09:55,10:40
大学英语,星期一,14:00,15:40
体育,星期三,16:00,17:40
```

- **星期几**：`星期一` / `周一` / `礼拜一` / `一` / `1` / `mon` / `monday` 都认。
- **时间**：`8:00`、`08：00`（全角）、`8点30`、`8.30`、`8`（= `8:00`）都认。

## 实现要点

- **`Slot` 用「从 0 点起的分钟数」存时间**，不用 `Time`：一是右端点可能是 `24:00`（1440 分钟），`Time` 的小时只能 0~23；二是 `Time` 只定义了 `__lt__`，没有 `__le__`，`t1 <= t2` 会直接 `TypeError`。
- **合并分两步**（这是「消碎片」的关键设计）：
  1. 按 `(星期几, 课程名)` 分组，组内按时间排序，`下一节开始 - 上一节结束 <= gap` 就接起来 —— 碎片在这里消失；
  2. 再把**不同课程之间真正重叠**的块合并成一块（撞车），但**不会**用 gap 去硬粘不同课程。
- **区间按左闭右开理解**（`[开始, 结束)`）：相接的两段不算重叠，所以永远不会冒出 `09:00-09:00` 这种 0 分钟的段。
- **`--gap` 对课表和空闲两个视图都生效**；空闲视图里时长 ≤ gap 的空档会标 `（课间）`。
- **合计只算上课时间**：所以 `共 4 节课，合计 4 小时 50 分钟`，而星期一显示的是合并后的 `09:00-10:40`。
- **星号导入的规则**：入口用 `from timetable import *`，能拿到的名字由库里的 `__all__` 决定。现在入口要用 `_ask`、`_fmt` 这类下划线开头的名字，所以破例把它们列进了 `__all__`。以后往库里加下划线开头的新函数，入口要用就必须加进这张表，否则运行到那一行才报 `NameError`。

## 已知限制

- 可用范围不能跨天（`22:00-02:00` 这种写法不支持）。
- 只支持一周 7 天，时间精确到分钟，没有单双周 / 多周。
- 相邻但不重叠的两段空闲不会被合并（`09:00-10:00` 与 `10:00-11:00` 算两段）。
- 合并只针对同一门课；不同课程挨着但不重叠时保持分开。
